# 세션 인수인계

## 언제
- 대화가 길어져 이전 지시를 놓치기 시작할 때
- 큰 방향 전환 직후
- 60~90분마다 한 번

## docs/HANDOFF.md 갱신 내용
1. 목표: 한 문장 (PLAN.md 문제 정의와 같아야 한다)
2. 현재 상태: 동작하는 것 / 아직 안 되는 것 / 확인 못 한 것
3. 최근 결정: DECISIONS.md에서 중요한 것 3개 이내 요약
4. 다음 할 일: 우선순위대로 3개, 각각 완료 조건
5. 주의할 점: 건드리면 안 되는 것, 알려진 함정
6. 실행법: 서버 실행, 테스트 실행 명령

## 새 세션에 줄 첫 지시
"AGENTS.md와 docs/HANDOFF.md를 읽고 현재 상태를 3줄로 요약한 다음, 다음 할 일 1번부터 진행해."

갱신한 뒤 커밋한다. 메시지: "docs: 인수인계 갱신".
