# 계약 (CONTRACT) v1

팀 모드에서 역할 세션들이 서로 기다리지 않고 동시에 일하기 위한 약속이다. PM만 고친다.
바꿀 때는 버전을 올리고 맨 아래 변경 이력에 적는다. 혼자 모드에서는 쓰지 않아도 된다.

## 폴더 소유권
| 경로 | 소유 |
|---|---|
| backend/core/, tests/core/ | backend-core |
| backend/app/, tests/app/, scripts/, Dockerfile, .env.example | backend-api |
| frontend/ | frontend |
| docs/status/<역할>.md | 각 역할 |
| docs/ 나머지 (docs/pm/ 포함), AGENTS.md, 과제 지정 문서 | PM |
